# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| older   | ❌        |

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report privately via GitHub's ["Report a vulnerability"](https://github.com/{{OWNER}}/{{REPO}}/security/advisories/new)
button, or email {{SECURITY_EMAIL}}.

You can expect an acknowledgement within 3 business days and a status update
within 10 business days. Please include steps to reproduce and the impact you
believe it has.
